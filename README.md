# Open Bristol Dataset: Interactive Map & Data Table

This project is a portfolio piece showcasing an embedded data table with an interactive map using ArcGIS. The dataset used is from the Open Bristol initiative, visualized in a dynamic and user-friendly interface.

## 🌍 Project Overview
- **Dataset:** Open Bristol Dataset
- **Technology Stack:** ArcGIS, JavaScript, HTML, CSS, DataTables.js
- **Features:**
  - Interactive map with geospatial data
  - Embedded dynamic data table
  - User-friendly filters and search functionality

## 📌 Live Demo
[Click here to view the live project](https://chathuwa-67.github.io/Fiverr_Order-1-Portfolio-for-Open-Bristol-Dataset/) 

## 🛠️ Installation & Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/Chathuwa-67/Fiverr_Order-1-Portfolio-for-Open-Bristol-Dataset.git
   cd OpenBristolMap
   ```
2. Open `index.html` in a browser.
3. Ensure internet access for ArcGIS API and DataTables.js.

## 📜 Usage
- Pan and zoom on the map to explore locations.
- Use the search bar to find specific data points.
- Click on map markers for additional details.

## 📚 Technologies Used
- **ArcGIS API for JavaScript** - Interactive mapping
- **DataTables.js** - Data table functionalities
- **Bootstrap** - Responsive design
